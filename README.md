# TPV Modular Desktop - Sprint 1

Base inicial del software TPV descargable.

## Requisitos

- Node.js instalado
- npm instalado

## Cómo instalar

```bash
npm install
```

## Cómo ejecutar en desarrollo

```bash
npm run dev
```

Esto abre Vite y luego Electron.

## Cómo generar instalador para Windows

```bash
npm run dist
```

El instalador se genera en:

```text
dist-installer/
```
